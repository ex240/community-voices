# Recorded example artifacts

These files are **recorded output from a real local run**, not live data.

| File | What it is |
| --- | --- |
| `sample-report.json` | RAG Community Voices report for a pinned seven-day window |
| `sample-comparison.json` | Same-window RAG vs no-RAG comparison |

They contain no API keys. Hacker News item links are public. Generating a fresh report still requires your own OpenAI API key. See the root README for the exact commands.
